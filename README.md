## ✨ Features (Diferenciais)

- 🌗 **Dark & Light Mode Nativo:** Transição suave entre um Dark Mode agressivo (Neon/Cobalt) e um Light Mode elegante com efeito Glassmorphism.
- 🦅 **Animações Customizadas:** Keyframes feitos sob medida (`float-raven`, `wing-sweep`, `fly-in-up`) garantindo uma interface viva e interativa.
- 📱 **100% Responsivo:** Experiência fluida em Desktops, Tablets e Mobile.
- 🎨 **Componentes Inteligentes:**
  - `Hero`: Layout imersivo com logotipo flutuante.
  - `Showcase`: Galeria dinâmica de projetos com filtros baseados em categorias.
  - `Packages` & `ProjectCalculator`: Simuladores de orçamento e cards de precificação atraentes.
- ⚡ **Zero Bloatware:** Arquitetura limpa utilizando o poder bruto do Vite + Tailwind v4, sem dependências desnecessárias.

## 💻 Como rodar localmente

Se você quiser clonar e brincar com o código no seu próprio ambiente:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/PetryckSlater/Vitrine01.git
   ```
2. **Entre na pasta do projeto:**
   ```bash
   cd Vitrine01
   ```
3. **Instale as dependências:**
   ```bash
   npm install
   ```
4. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```
5. Acesse `http://localhost:5173/` no seu navegador.

## 📁 Estrutura do Projeto

A lógica principal do site está separada de forma modular. Para alterar as configurações gerais (textos, pacotes, portfólio), basta editar o arquivo de configuração central:

`src/config/siteConfig.ts` -> Arquivo mestre que controla os dados exibidos no site.
